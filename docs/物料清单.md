## 说明

- 电量采样取电池端 B+：390 kΩ／10 kΩ 分压进 A0，为最终样机实际阻值。
- UP／DOWN 两键在开机、复位和烧录期间必须松开（D8 启动需为低，D4 需为高）。
- 屏幕的 SDA／SCL 是 SPI，传感器同名 SDA／SCL 是 I²C，分别接线，不可并接。
- 全部外围与主控共地；屏幕和传感器用开发板 3V3。
- 外壳（4 件打印品）见 `casing/output/`；固件与烧录见 `firmware/` 与 [../README.md](../README.md)；打印用 3MF 一键配置见 MakerWorld 模型页。
