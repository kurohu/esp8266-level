# 使用与调试

## 操作

| 动作 | 测量页 | 菜单 |
|---|---|---|
| 短按 UP | HOLD，冻结当前读数。再按恢复 | 修改当前值或执行当前项 |
| 短按 DOWN | 将当前姿态设为 PIN 目标。再按退出 PIN | 依次切换选项 |
| 长按 UP 约 0.7 秒 | 打开圆盘菜单 | 退出菜单。校准子页先返回上一级 |

- 屏幕朝前时测长边角度，显示 0～90°，数字可随重力旋转。屏幕朝上时显示双轴气泡，X／Y 各显示有符号角度。
- PIN 开启后，固定在进入时的测量页。圆盘立即变深蓝，中央继续显示实际角度。立放时外圈蓝色短线表示锁定位置，浅色弧段显示相对于锁定位置的偏差。进入公差后中央变亮蓝、移动弧段收起。按 DOWN 退出后恢复姿态自动切换。
- HOLD 只用于冻结读数，可在普通测量或 PIN 测量中使用。PIN 记录的是当前会话目标，重新开机要重新设定。

## 菜单

| 菜单 | 功能 | 出厂默认 |
|---|---|---|
| SOUND | 开／关提示音 | 开 |
| TOLERANCE | 0°、±0.05°、±0.1°、±0.5°、±1.0° | ±1.0° |
| SNAP | 普通测量到位时，显示值吸附到目标。PIN 显示实测值 | 开 |
| SLEEP | 1、3、5 分钟或永不。静置后关闭显示内容，明显移动或按键唤醒 | 3 分钟 |
| CAL | 六面标定与当前姿态归零 | — |
| EXIT | 返回测量 | — |

缓慢靠近目标时，立放（含 PIN）在 **10°** 内、平放在 **12°** 内进入引导区。固件需先检测到约 **0.6°** 的变化，随后以 **1.6 kHz、35 ms** 的短滴提示，越接近目标越密。进入公差时响两声 **170 ms → 停 125 ms → 200 ms**，停在目标时不持续重复。平放到位需要 X、Y 两轴都进入容差。0° 公差档按固件的 0.01° 读数判断；它描述触发窗口，不代表传感器具有 0.01° 的绝对精度。

屏幕 BL 接 3V3，因此 SLEEP 期间背光仍亮。菜单设置和校准数据写入开发板 Flash 的 EEPROM 模拟区。

## 六面标定

1. 在整机装配完成后，进入 CAL → SIX FACES。短按 UP 开始。
2. 以屏幕朝向自己、文字正立时的边为准，按提示依次摆放。

| 屏幕提示 | 接触基准面的部位 |
|---|---|
| BOTTOM DOWN | 原来的底边 |
| TOP DOWN | 原来的顶边 |
| LEFT DOWN | 原来的左端 |
| RIGHT DOWN | 原来的右端 |
| SCREEN UP | 屏幕朝上，背面朝下 |
| SCREEN DOWN | 屏幕朝下，正面朝下 |

3. 每面放稳，短按 UP。固件先等 **2 秒**，再采样约 **1.2 秒**。看到 UP TO RETRY 时，只重采当前面。标定参数在六面全部通过后保存，看到 SAVED 即完成。
4. 如果最后仍提示 FACE RETRY，核对六面方向与基准面，必要时长按 UP 退出后重做整轮。完成新一轮六面标定会清除之前的零点微调。

ZERO CURRENT 用于微调。将整机立放或屏幕朝上静置在已知水平面，在 CAL 中用 DOWN 选 ZERO CURRENT，再按 UP。立放和平放零点分开存储，两种姿态各做一次。

## 工作原理

MPU6050 采集三轴加速度，静止或缓慢移动时用重力分量求姿态。六面标定求零偏和校正矩阵，补偿各轴比例差异、轴间耦合及模组安装方向。程序对加速度做一阶滤波，再按重力投影决定普通测量页的立放／双轴模式。PIN 用当前斜率作参考，读数与导向提示分别使用实测角度和目标偏差。

NodeMCU 用 4 MHz SPI 将 RGB565 图像写入 ST7789，圆盘与字体在固件中绘制。A0 电压每 500 ms 采样并平滑，样机以 **4.165 V 对应 ADC 42** 做单点估算。固定分档阈值是 ADC **36** 和 **39**，约对应 **3.57 V** 和 **3.87 V**，边界有约半个 ADC 计数的回差。图标是粗略电压档位。ADC 不在 20～55 时图标隐藏。换不同 NodeMCU 板复刻时用万用表与串口核对读数；复刻包未调整固定阈值。

## 上电验收与排错

| 检查 | 预期或处理 |
|---|---|
| USB 连线与启动 | 串口能枚举，115200 波特率下能看到 BAT ADC 与 X/Y/Z 测角输出。烧录时松开外接按键 |
| 屏幕 | 上电可见横屏圆盘。只有背光时先查 CS、DC、RST、SDA、SCL |
| 传感器 | 改变角度时串口原始值变化。MPU6050 read failed 时核对 GND、3V3、0x68 和 SDA/SCL |
| UP／DOWN | UP 短按 HOLD、长按菜单；DOWN 短按 PIN、再按退出。PIN 开启时翻转设备不切页 |
| 校准 | 在可信基准面检查立放 0°／90° 和平放 X/Y 零点。人为晃动时应能重采当前面 |
| 提示音 | SOUND 开启后，从目标外缓慢接近，有引导短滴与到位双声 |
| 电量 | 装电池时串口 BAT ADC 应有合理值，例如样机满电附近约 42、bars=3。若为 0.0，先量 B+ 和 A0，再检查分压接线 |
