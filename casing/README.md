# ESP8266 电子水平仪外壳 · 机械复刻包

底壳 174 × 50 × 34 mm，合盖后 174 × 50 × 36 mm。设计以现有模块为基准，通过定位柱、托台和独立压板固定，避免插拔接口时由焊点承力。后盖带电池盒，可整体拆出。此目录是机械复刻包。整机接线、固件和校准见上一级的 [项目说明](../README.md)、[硬件接线与组装](../硬件接线与组装.md) 和 [使用与调试](../使用与调试.md)。

## 从哪里开始

|文件|用途|
|-|-|
|`cad/model.py`|参数化源文件，可在 CQ-editor 中打开|
|`build.py`|检查实体及模型中已定义的装配包络，重新导出|
|`output/casing.\*`|底壳，含屏幕窗、按键指窝、充电口、开关孔、烧录口及扎线点|
|`output/cover.\*`|后盖，含电池沉槽、走线槽及两端固定孔|
|`output/charger\_pressure\_plate.\*`|独立充电板压片，避让尾端焊盘和定位缺口|
|`output/node\_usb\_cover.\*`|左侧烧录口可拆补片，带定位凸台和平底沉孔|

STL 用于切片，单位 mm。STEP 用于 CAD 检查或交换。源码是尺寸变更入口。复现环境为 **Python 3.13.15 + CadQuery 2.8.0**。在项目目录用上述环境运行 `python -m pip install -r requirements.txt`，再运行 `python -X utf8 build.py`。正常结果为四个有效单实体及各自 STEP/STL。

## 紧固与装配

|位置|数量|自攻螺丝试装值|导孔 × 深度（mm）|
|-|-:|-|-|
|屏幕|4|M2×3 圆头|Ø1.8 × 4.0|
|烧录口补片|1|M2×2 圆头|Ø1.8 × 1.5|
|NodeMCU / MPU / 按键 / 蜂鸣器|4 / 2 / 4 / 1|M2.6×5 圆头|Ø2.3 × 4.4 / 4.2 / 5.05 / 4.7|
|充电板压片|1|M2.6×6 圆头|Ø2.3 × 5.8|
|电池盒|2|M2.6×4 圆头，夹持厚 2 时|Ø2.3 × 2.2|
|后盖两端|2|M3×8 沉头|Ø2.5 × 4.7|

圆头按头下长度，沉头按含头总长。先量实际夹持厚度，确认螺尖有余量。M2.6 的 Ø2.3 导孔是打印试装后调整值，先在小样上手拧确认。原 Ø2.2 孔曾发生柱身裂响和中段断裂。

1. 底壳前面板朝下切片。后盖外面朝下，压板平放，USB 补片外侧朝下。检查 0.4 mm 薄窗与指窝孔缘是否有连续走线，检查 Type‑C 上边和补片沉孔的桥接。先用 0.20 mm 层高作为试打起点。
2. 后盖拆开时先装蜂鸣器。螺丝从腔内向顶壁拧。再装屏幕、NodeMCU、MPU、按键。试按回弹、试插烧录线，确认 PCB 能平贴支撑。
3. 充电板两缺口落入定位凸耳，尾端焊线走左下缺口，压片避开焊锡。用实际 Type‑C 线验证能插到底。单独试装开关卡扣和接线。
4. 空电池盒先锁进后盖，再接线合盖。线束沿 X 布置，扎带从前后方向穿耳。给翻盖留线长，避免夹线。确认屏幕接头、开关端子和电池线束在合盖时互不挤压。

实板版本、打印孔径、焊点高、插头塑胶头及出线弯折均可能改变配合。构建中的无干涉结果只覆盖建模包络。整机装好后用实际接触底面校零。
